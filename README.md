# AI-Powered Personalized Smart Study Planner

This project framework was created and submitted for the **Hack'em Hex Hackathon (IEEE)** by Team AI Pioneers.

## 📌 Project Overview
Students face difficulty in managing college schedules, assignments, and exams manually. Our solution is a smart AI Chatbot and centralized interactive Planner application that automatically tracks deadlines and uses Machine Learning logic to auto-generate a customized daily study schedule.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend:** HTML, CSS, JavaScript
- **AI/ML:** Open-source pre-trained model APIs & Scheduling algorithms
- **Version Control:** GitHub
